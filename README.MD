# Mitos y Leyendas de La Pampa

Un proyecto 2D en Godot pensado para la GameJam con personajes y entes de diferentes mitos y leyendas del folklore de La Pampa

## Requisitos

- Godot Engine 4.7.2 o superior
- Git
- Terminal o Git Bash
- La carpeta del proyecto descargada localmente

## Como clonar el repositorio

1. Abre tu terminal o Git Bash.
2. Ejecuta este comando:
   `git clone https://github.com/juanvaz25/GrupoSiete.git`
3. Entra a la carpeta creada:
   `cd GrupoSiete`
4. Verifica que exista el archivo `project.godot` dentro del proyecto.
5. Si no aparece, asegurate de haber descargado la carpeta completa del repositorio.

## Como abrir el proyecto en Godot

1. Abre Godot Engine.
2. Selecciona la opción "Importar" o "Open Project".
3. Busca la carpeta del proyecto y abre el archivo `project.godot`.
4. Espera a que Godot cargue todas las escenas y archivos del juego.
5. Presiona el botón "Ejecutar" para probar la versión actual.

## Observaciones

- Si el proyecto no abre correctamente, revisa que tu versión de Godot sea compatible.
- Si aparecen errores de escenas o scripts, controlá que todos los archivos estén presentes.
- Si querés modificar o seguir desarrollando el proyecto, podés trabajar directamente desde la carpeta local.
